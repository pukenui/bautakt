# Pläne

Ein Projekt kann mehrere unabhängige Terminpläne enthalten (z. B. „Rollen-Netzplan“ für F.1
und „Terminplan Gesamtprojekt“ für F.2).

## Typische Abläufe

1. Namen eingeben und **Neuer Plan** wählen.
2. **Umbenennen**: neuen Namen eingeben, mit Eingabetaste bestätigen (Esc bricht ab).
3. **Löschen** entfernt den Plan. Mit **Strg+Z** lässt sich jede Änderung rückgängig machen.

## Tastenkürzel

| Kürzel | Wirkung     |
| ------ | ----------- |
| Strg+Z | Rückgängig  |
| Strg+Y | Wiederholen |
| Strg+S | Speichern   |
