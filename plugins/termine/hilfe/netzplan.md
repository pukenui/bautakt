# Netzplan

Vorgangsknotennetz nach DIN 69900 im Format der Übung:

| Nr. Vorgang |          |     |
| ----------- | -------- | --- |
| FAZ         | D        | FEZ |
| SAZ · GP    | FP · SEZ |     |

Zeiten in Arbeitstagen, Zeitpunkte ab 0. Am Pfeil steht die Beziehung, z. B. `+10EA`.
Der kritische Weg ist rot und dick.

## Typische Abläufe

1. Die Knoten werden automatisch in Spalten angeordnet.
2. Knoten ziehen verschiebt ihn; die Position wird gespeichert (rückgängig machbar).
   **Automatisch anordnen** setzt alle Positionen zurück.
3. Am Punkt rechts am Knoten ziehen und auf einem anderen Knoten loslassen legt eine
   Beziehung Ende → Anfang an. Art und Abstand ändern Sie per Doppelklick auf den Pfeil.
4. Pfeil anklicken und **Entf** löscht die Beziehung.
5. Start- und Ende-Meilenstein (z. B. „Beauftragung“, „Abnahme“) legen Sie im Terminplan als
   Meilensteine an.

## Tastenkürzel

| Kürzel          | Wirkung                    |
| --------------- | -------------------------- |
| Entf            | gewählte Beziehung löschen |
| Strg+Z / Strg+Y | Rückgängig / Wiederholen   |
